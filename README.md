## Projects

**[m365-admin-mcp](https://github.com/Tanarius/m365-admin-mcp)**: An MCP server that lets Claude answer Microsoft 365 and Entra admin questions (MFA gaps, inactive accounts, license usage) through Microsoft Graph. Read-only, four fixed tools, tenant lock, row cap, and an audit log. Verified against a live test tenant.

**[Spotter](https://github.com/Tanarius/spotter)**: A personal AI agent on Telegram that runs 24/7. Tool calling across 8 tools, layered memory in SQLite, scheduled jobs, deployed on Railway.

**[Simmer](https://github.com/Tanarius/simmer)**: A live meal-planning web app ([simmer.kitchen](https://simmer.kitchen)) with user accounts, Stripe payments, per-household data isolation, and two AI models routed by cost.
